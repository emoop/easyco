## Promo codes {#action-promo-overview}

A promo code is a discount the customer types in the cart. You find them under "Marketing" → "Promo codes" (the "Manage promotions" permission is needed).

Every code has a **type** (a percentage or a fixed amount) and a **value**. The type, the value and the code itself **cannot be changed** after creation: if you need a different discount, create a new code (the "Duplicate" button copies the conditions of the old one) and switch the old one off.

A promo code is **never deleted**, because orders keep its history. You switch it off with the "Active" switch or from the "Actions" menu in the list.

The conditions are optional: a minimum and a maximum amount, new customers only, exclude sale items, individual use only, limits on the number of uses and a validity period.

## What the discount applies to {#action-promo-scope}

With no scope the code applies to the whole cart. With a scope the discount is limited to chosen brands, categories, tags, products or attribute values.

- **Only for** – the discount applies only to the chosen ones.
- **Except** – the chosen ones are left out.

The two kinds can be combined. You choose from the list of existing records (products are searched by name or SKU).

## Public code {#action-promo-public}

A public code is shown to **every visitor** of the cart under "Find a promo code", together with a short description that you write (up to 120 characters, plain text). If the cart already meets its conditions there is an "Apply" button next to it. If the amount is too low, it shows how much is missing.

**The code itself is public by design:** do not keep it secret. If you want a code for one customer only, leave it non-public.

A public code **without a condition** is a permanent discount for everybody. The form warns you (the yellow message) and tells you what to add: a minimum amount, a scope, a first order, an end date or a limit. The warning does not stop you from saving.
